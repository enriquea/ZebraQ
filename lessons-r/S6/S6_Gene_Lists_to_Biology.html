3. Build the gene lists

An enrichment tool takes a set of genes, not a ranked table. So the first decision is which genes get in.

# padj  : how confident are we that this gene changed at all
# log2FoldChange : how much did it change
#
# Both matter. A gene can be significant and barely move; a gene can move a lot
# and be noise.
padj_max = 0.05
lfc_min  = 1

de = res %>%
  filter(!is.na(padj), padj < padj_max, abs(log2FoldChange) > lfc_min)

genes_up   = sort(de$gene[de$log2FoldChange > 0])
genes_down = sort(de$gene[de$log2FoldChange < 0])

length(genes_up)
## [1] 354
length(genes_down)
## [1] 588

Notice that these cutoffs are not the ones the volcano plot used in S5 (padj < 0.001, |log2FC| > 2.5, which keep only 48 and 55 genes).

That was not an inconsistency. The volcano’s cutoffs exist so the gene labels stay readable on a crowded figure. Choosing genes for enrichment is a different job, and it gets its own decision. Be suspicious of any analysis that reuses a threshold without saying why.

4. Where a gene list can be taken

A gene symbol is a key into a large number of public databases. Knowing which one answers which question is most of the skill.

Resource Answers
NCBI Gene What is this gene, in any organism?
Ensembl Where is it in the genome, and what is its equivalent in another species?
ZFIN Everything zebrafish: expression patterns, mutants, phenotypes
UniProt What does the protein do, and what does it look like?
GO Controlled vocabulary of biological processes, functions and locations
KEGG / Reactome Curated pathway maps
STRING Which proteins interact with which
Enrichr Is my gene list unusually full of any of the above?

The one we need now is the last. We have 588 down-regulated genes; we want to know whether they share anything beyond being on the same list.

5. Enrichment: the idea

Enrichment asks one question, repeated thousands of times:

Of the 588 genes on my list, 21 are annotated “extracellular matrix organization”. The genome has 92 such genes in total. Is 21 more than I would expect by chance?

That is a hypergeometric test, the same mathematics as drawing coloured balls from an urn. Doing it for every GO term at once is why the output has an adjusted p-value column: thousands of tests need a multiple-testing correction, exactly as in S4.

# "Overlap" arrives as the text "21/92". Split it to get a gene ratio.
plot_data = sig_down %>%

8. Read the genes, not the term

A GO term is a label attached by a curator, sometimes decades ago, sometimes by an automatic pipeline. The label can be misleading even when the statistics are correct. The Genes column is the evidence, and it takes ten seconds to read.

Look at those five rows carefully before reading on.

Three things should bother you.

The top term is one gene family. All 21 genes behind “extracellular matrix organization” are collagens, plus one collagen cross-linking enzyme. That is a real and coherent finding, but it is one story, not 21 independent ones.

Three terms are the same genes wearing different hats. “Notochord morphogenesis” and “skeletal system development” are driven by the same collagens as the term above them. Ranked lists make these look like three findings. They are one.

One term is not about what it says. “Cellular response to radiation” is carried by opn1sw1, opn1sw2, rhol, rho, opn4a, opn1lw2, opn1mw1 — seven opsins and a rhodopsin. There is no radiation in this experiment. These are the same photoreceptor genes that drive “response to light stimulus”, and they are annotated to a radiation term because light is electromagnetic radiation.

So the rule, which is worth more than any of the code above:

Never report a GO term before reading the genes that produced it.

One more thing to notice, because S7 begins here. Lower-casing a human symbol to match a zebrafish one is a crude way to connect two species. It finds col1a2, but it misses col1a1a and col1a1b — the two zebrafish copies of human COL1A1 — because zebrafish duplicated its genome and renamed the copies.

Matching species properly is the subject of the next lesson.
